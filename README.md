# Khaya Manoto - Portfolio Website

A modern, responsive portfolio website for Khaya Manoto, showcasing skills as a Software Developer & Security Engineer.

## Features

- 🎨 **Modern Design** - Clean, professional design with gradient accents
- 📱 **Fully Responsive** - Works on mobile, tablet, and desktop
- ⚡ **Fast Performance** - Optimized loading and animations
- 🔒 **Security Focus** - Highlights cybersecurity expertise
- 📊 **Data Skills** - Showcases Data Engineering and Analytics capabilities
- 🐍 **Python Emphasis** - Features Python development skills prominently
- 💼 **Project Management** - Interactive project showcase with add/remove functionality
- 📞 **Contact Form** - Professional contact section with form validation

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter & Space Mono)
